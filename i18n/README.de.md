## Einführung

Das Projekt ist nach professionellen Projektstrukturen standardisiert und unterstützt eine effiziente Quellcodeverwaltung über Git.

<a id="features"></a>
## Hauptmerkmale

- Schnelle Einrichtung und professionelle Paketierung.
- Leichte Konfiguration, einfach zu warten und zu erweitern.
- Automatisierter Git-Push-Workflow mit dem mitgelieferten Skript.

## Verzeichnisstruktur

```text
JA_Route/
├── lib/                       # Application source code
│   ├── main.dart              # Program entry point
│   ├── models/                # Data models
│   ├── services/              # Business logic and APIs
│   └── widgets/               # UI component widgets
├── assets/                    # Statische Ressourcen der Anwendung
├── .gitignore                 # Git-Ausschlussmuster
├── README.md                  # Projektdokumentation (diese Datei)
├── LICENSE                    # Lizenzdatei
├── ABOUT.txt                  # Kurzbeschreibung des Projekts
├── git_push.bat               # Automatisches Push-Skript für GitHub
└── pubspec.yaml               # Flutter package dependencies and version
```

<a id="setup"></a>
## Installations- und Benutzerhandbuch

### Systemanforderungen
*   Betriebssystem: **Windows 10/11**
*   Interpreter: **Python 3.13** oder gleichwertige Umgebung.

<a id="quick-start"></a>
### Ausführung
1. Erforderliche Abhängigkeiten installieren:
   ```cmd
   flutter pub get
   ```
2. Anwendung ausführen:
   ```cmd
   flutter run
   ```
