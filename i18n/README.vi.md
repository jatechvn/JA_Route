<a id="introduction"></a>
## Giới thiệu

Dự án được chuẩn hóa theo cấu trúc thư mục chuyên nghiệp, hỗ trợ quản lý mã nguồn hiệu quả qua Git.

<a id="features"></a>
## Tính năng nổi bật

- Thiết lập nhanh chóng và đóng gói chuyên nghiệp.
- Cấu trúc tinh gọn, dễ dàng bảo trì và phát triển thêm.
- Quy trình đẩy code lên Git tự động hóa thông qua script đi kèm.

---

## Cấu trúc thư mục

```text
JA_Route/
├── lib/                       # Thư mục chứa mã nguồn chính
│   ├── main.dart              # Điểm khởi chạy ứng dụng
│   ├── models/                # Thư mục chứa các mô hình dữ liệu
│   ├── services/              # Các dịch vụ xử lý logic chính
│   └── widgets/               # Các widget giao diện người dùng
├── assets/                    # Tài nguyên tĩnh (hình ảnh, cấu hình mặc định...)
├── .gitignore                 # Các mẫu loại trừ khỏi Git
├── README.md                  # Tài liệu hướng dẫn (chính là file này)
├── LICENSE                    # File bản quyền phần mềm
├── ABOUT.txt                  # Thông tin tóm tắt về dự án
├── git_push.bat               # Script tự động đẩy code lên GitHub
└── pubspec.yaml               # Cấu hình thư viện và phiên bản ứng dụng
```

<a id="setup"></a>
## Hướng dẫn cài đặt & Sử dụng

### Yêu cầu hệ thống
*   Hệ điều hành: **Windows 10/11**
*   Trình thông dịch: **Python 3.13** hoặc môi trường tương đương.

<a id="quick-start"></a>
### Cách khởi chạy
1. Cài đặt các thư viện cần thiết:
   ```cmd
   flutter pub get
   ```
2. Chạy ứng dụng:
   ```cmd
   flutter run
   ```
